# Vince Moretto Álvarez — Portfolio

Static portfolio site (HTML, CSS, JS, assets). No build step required.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Deploy

See the project handoff: `docs/chatgpt-migration.md` (GitHub account → public repo → GitHub Pages → Namecheap DNS).

## Contents

- `index.html` — page structure and copy
- `style.css` — styles
- `site.js` — case-study expand / hash behavior
- `favicon.png` — site icon
- `assets/` — images, résumé PDF, Weekly Watch video sample
